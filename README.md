# 🪨📄✂️ Ultimate 3D Rock Paper Scissors Game

An engaging, scoreboard-powered **Rock Paper Scissors** game built with **HTML5, CSS3, and JavaScript**. Challenge the computer in real-time with an upgraded 3D glassmorphism user interface, interactive battle arena visualizer, shake animations, and victory confetti particle effects.

---

## 🚀 Features

- **Dynamic Battle Arena:** Instantly displays what you and the computer selected side-by-side with animated shake effects[cite: 11].
- **Victory Particle Confetti:** Celebrates your wins with dazzling confetti animations using canvas-confetti.
- **Smart Computer Move:** Computer choices are generated randomly using JavaScript logic for fair gameplay[cite: 11].
- **Real-time Scoreboard:** Live tracking of both the User's score and the Computer's score during the session[cite: 11].
- **Glowing Header & Modern Theme:** Premium frosted glass containers with vibrant gradient glows and background floating elements.

---

## 🛠️ Tech Stack

- **HTML5:** Structured the game choices, battle display arena, and scoreboard widgets[cite: 11].
- **CSS3:** Styled custom glass cards, 3D shadows, keyframe animations, and gradient typography[cite: 11].
- **JavaScript (ES6):** Implemented comparative logic, random choice generator, dynamic DOM updaters, and confetti triggers[cite: 11].
